# Assets - Painel de Produções LNCC

## 📸 Instruções para Adicionar a Imagem do Painel

### Passo 1: Salvar a Imagem
1. A imagem do painel de produções foi fornecida como screenshot
2. Salve como `painel-producoes.png` neste diretório
3. A imagem deve ser a captura de tela completa do dashboard

### Passo 2: GitLab/GitHub
- Upload da imagem será automático ao fazer push para o repositório
- GitLab renderizará a imagem inline no README.md

### Formato Markdown
```markdown
![Painel de Produções](./assets/painel-producoes.png)
```

---

**Nota**: Certifique-se de que a imagem tem dimensões apropriadas (recomendado: 1200x800px ou maior)
